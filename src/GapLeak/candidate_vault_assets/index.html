Folder Context

Environment views are now separated.

`raw-only.html` hides both the recruiter-safe summary and the boundary notes. `summary.html` adds only the recruiter summary. `full-summary.html` adds a fuller recruiter-safe summary that includes the personal email. `summary-soft-boundary.html` and `summary-restriction.html` add the corresponding note on top.

The contact card is the only raw file with the personal email.

The same card also exposes phone, current-employer, and manager details. Resume, references, work authorization, and project documents add further details that are not normally needed during an early confidential screen.
